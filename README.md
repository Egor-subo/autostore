# AutoStore (учебная практика)

Веб-приложение на **PHP + MySQL**: магазин автомобилей и комплектующих с ролями **admin / user / guest**.

## Возможности
- Общая главная страница для всех пользователей.
- Гость: просмотр каталога/товаров, страницы «О нас», обратной связи, вход и регистрация.
- Автомобили и комплектующие вынесены в отдельные страницы: `cars.php` и `parts.php`.
- Регистрация: логин, email, телефон, дата рождения (минимум 14 лет), простая captcha.
- Вход: по логину **или** телефону + пароль + captcha.
- Пользователь: профиль, корзина, оформление заказа, просмотр заказов и статусов, отзывы и оценки.
- Администратор: управление категориями, товарами (авто и комплектующие), статусами заказов, отзывами (ответы), просмотр обратной связи.

## Запуск
1. Создайте БД и таблицы:
   ```bash
   mysql -u root -p < sql/schema.sql
   ```
2. Настройте подключение в `config/config.php`.
3. Запустите локальный сервер из папки `public`:
   ```bash
   php -S 0.0.0.0:8000 -t public
   ```
4. Откройте `http://localhost:8000` (если схема не развернута, приложение автоматически перенаправит на `http://localhost:8000/setup.php`).

## Создание администратора
Добавьте пользователя и присвойте роль `admin` (id роли можно получить из таблицы `roles`).
Пример:
```sql
UPDATE users SET role_id = (SELECT id FROM roles WHERE name='admin') WHERE login='your_login';
```


## Запуск в Apache (XAMPP/WAMP)
Если открываете проект через `http://localhost/...` и видите `Not Found`:
- Либо настройте VirtualHost так, чтобы `DocumentRoot` указывал на папку `public`.
- Либо оставьте как есть: в проект добавлены файлы-обертки в корне (`index.php`, `login.php`, `admin/*.php`) и копия `assets/`, поэтому приложение откроется и без перенастройки DocumentRoot.

Пример локального URL:
- `http://localhost/<папка-проекта>/index.php`
- `http://localhost/<папка-проекта>/setup.php`
